# 串口调试助手插件仓库

这是串口调试助手的插件仓库，用于存放各种扩展功能的插件。

## 主界面仓库

串口调试助手主界面仓库：[https://github.com/monkes/serial-debug-assistant-ui](https://github.com/monkes/serial-debug-assistant-ui)

## 使用方法

1. 克隆或下载此仓库到本地
2. 打开调试助手主界面
3. 在主界面菜单中点击"插件" -> "加载插件"
4. 找到你下载的插件目录，双击加载插件
5. 加载成功后，插件将显示在主界面右侧的插件列表中
