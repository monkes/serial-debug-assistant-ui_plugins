# 串口调试插件

这是一个基于PyQt5的串口调试插件，用于串口通信的调试和测试。

## 功能特性

- 串口参数配置（端口、波特率、数据位、停止位、校验位）
- 支持多种波特率（300-921600）
- 支持文本和十六进制格式的数据发送和接收
- 实时接收和显示串口数据
- 支持自动滚动显示最新数据
- 支持添加时间戳
- 支持保存接收到的数据
- 支持DTR和RTS信号控制
- 支持多线程读取数据，避免界面卡顿

## 安装方法

1. 克隆或下载此仓库到本地
2. 在主界面->插件->加载插件->找到你下载的位置双击，软件自动加载此插件

## 使用方法

1. 在主界面右侧点击串口调试，即串口调试窗口
2. 在串口设置区域选择串口端口和配置参数
3. 点击"打开串口"按钮打开串口
4. 在发送区域输入要发送的数据，点击"发送"按钮发送数据
5. 接收到的数据会显示在接收区域
6. 可以使用"清空接收"按钮清空接收区域
7. 可以使用"保存数据"按钮保存接收到的数据
